# expense-ledger-cli product specification

> Generated by sdd-factory. Version 0.1.0; every record is `proposed` until the pre-authorised approval.

---

## 1. Context

A small command-line tool called `ledger` records personal expenses in a JSON ledger file and reports on them: it adds an expense, lists expenses with filters, summarises totals per category, removes an expense and exports the ledger as CSV. The ledger file path comes from the environment variable `LEDGER_FILE` and defaults to `./ledger.json`; an absent file is an empty ledger. The tool is invoked as `node dist/cli.js <command>` and communicates through stdout lines, one-line stderr diagnostics and exit codes.

---

## 2. Glossary

- **expense**: one recorded expenditure with an `id`, an `amount`, a `category`, a `date` and an optional `note` (source L9).
- **id**: the integer expense identifier starting at 1 and never reused within a ledger file, held by every expense (source L9).
- **ledger**: the set of expenses held in one ledger file (source L5-L9).
- **ledger file**: the JSON file holding the ledger, at the path given by `LEDGER_FILE`, default `./ledger.json` in the current working directory (source L7).
- **amount**: a positive decimal with at most two fractional digits, stored as an integer number of cents and rendered with exactly two decimals (source L13).
- **amount cents**: the integer cent value of an amount (`12.50` is 1250) (source L13).
- **category**: a label of 1 to 20 characters drawn from lowercase letters, digits and `-` (source L9).
- **date**: a calendar day written `YYYY-MM-DD` (source L9).
- **note**: optional free text attached to an expense (source L9).
- **month**: a calendar month written `YYYY-MM` (source L17).
- **total**: the sum of the amounts of the counted expenses, rendered like an amount (source L17).
- **today in UTC**: the current calendar day in the UTC time zone (source L13).
- **usage text**: the text printed by `ledger --help`, naming the add, list, summary, rm and export commands and the `--help` option (source L23).
- **usage error**: a rejected command line, reported as one line on stderr starting with `usage:` with exit code 2 (source L27).
- **error exit**: a failure reported as one line on stderr starting with `error:` with exit code 1 (source L28-L29).
- **exit code**: `0` success, `1` error exit, `2` usage error (source L27-L30).
- **CSV export**: the ledger rendered with header `id,date,amount,category,note`, one row per expense (source L21).

## 19. Out of scope

- Currencies other than the single implicit unit of the ledger, budgets, recurring expenses and editing of an already recorded expense (source L34).
- Concurrent access handling for one ledger file (source L35).
- Any network service, sync or multi-user sharing of the ledger.
