# todo-cli product specification

> Generated by sdd-factory. Version 0.1.0; every record is `proposed` until the pre-authorised approval.

---

## 1. Context

`todo` is a small command-line task list written in TypeScript. It keeps a list of tasks in a JSON file whose path comes from the environment variable `TODO_FILE` (default `./todo.json`) and lets the user add, list, complete and remove tasks. Every invocation is one short-lived process that resolves the storage file, performs exactly one command and exits with 0, 1 or 2. The product has no network component, no interactive mode and no concurrent access handling.

## 2. Glossary

| Term | Meaning | Source |
| --- | --- | --- |
| task | One entry of the list, carrying an `id`, a `text`, a `done` flag and a `createdAt` timestamp. | L9 |
| storage file | The JSON file that holds the list of tasks. | L7 |
| `TODO_FILE` | Environment variable holding the path of the storage file; when it is not set the path is `./todo.json` in the current directory. | L7 |
| id | Integer identifier of a task, starting at 1, never reused within a file. | L9 |
| text | Free-text description of a task. | L9 |
| done | Boolean flag of a task: true means completed, false means open. | L9 |
| `createdAt` | ISO-8601 timestamp recording when the task was created. | L9 |
| open task | A task whose `done` is false. | L14 |
| completed task | A task whose `done` is true. | L14 |
| command | One of `add`, `list`, `done`, `rm`, `--help`. | L13-L17 |
| usage error | Failure with exit code 2 and a one-line stderr message starting with `usage:`. | L21 |
| store error | Failure with exit code 1 and one stderr line, either `error: no task #<id>` or `error: cannot read <path>`. | L22-L23 |
| usage text | The text printed by `todo --help`. | L17 |
| store | The storage file as one invocation sees it: absent, empty, or holding a task list. | L7-L9 |
| contract shape | The JSON root and task shape defined by todo-cli:CTR-006: a root object with `nextId` and `tasks`, every task carrying `id`, `text`, `done` and `createdAt`. | L9 |
