# todo-cli product specification

> Generated by sdd-factory. Version 0.1.0; every record is `proposed` until the pre-authorised approval.

---

## 1. Context

A small command-line task list named `todo`. It keeps tasks in a JSON file and lets the user add, list, complete and remove tasks (`source: L3`). The CLI is invoked as `node dist/cli.js <command>` (`source: L34`).

---

## 2. Glossary

| Term | Definition | Source |
| --- | --- | --- |
| task | One entry in the task list, with an integer `id`, a `text` string, a `done` boolean and a `createdAt` ISO-8601 timestamp. | L9 |
| storage file | The JSON file that holds the tasks; its path comes from `TODO_FILE` or defaults to `./todo.json` in the current directory. | L7 |
| open task | A task whose `done` value is false. | L9, L14 |
| completed task | A task whose `done` value is true. | L9, L15 |
| usage text | The help output printed by `todo --help`. | L17 |
| path | The storage file location as taken from `TODO_FILE` or the default `./todo.json`; a relative `TODO_FILE` value and the default `./todo.json` both resolve against the current working directory of the invocation. | L7, L23 |
