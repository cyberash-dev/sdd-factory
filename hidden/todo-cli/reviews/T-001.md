## Findings

RV-001 — advisory, spec_ids `todo-cli:CTR-006`, `todo-cli:BEH-019`. `todo-cli:CTR-006.preconditions` says "the file path is resolved from TODO_FILE or ./todo.json in the current directory"; `src/store/index.ts:23` adds `configured !== ""`, i.e. an empty-string `TODO_FILE` is silently treated as unset and the default path is used. It endangers no clause and the tests do not exercise it; recorded so the trace shows the choice was seen.
