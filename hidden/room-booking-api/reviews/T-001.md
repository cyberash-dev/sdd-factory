## Findings

### RV-001 — advisory — implementer

- spec_ids: `room-booking-api:INV-001`
- evidence: `room-booking-api:INV-001.statement` — "booking ids are b followed by the next decimal counter value; counters advance in creation order across all rooms, ids are unique, and a deleted id is never assigned again"; `src/store/index.ts:65` — `const booking: Booking = { id: `b${bookingCounter}`, ...input };` spreads the caller argument after the assigned id, so an argument object that already carries an `id` property (legal for a non-literal argument under structural typing, since `NewBooking` is only `Omit<Booking, "id">`) silently replaces the server-assigned id rather than being ignored.
- effect: today every realised call path assigns the counter id, so INV-001 is proven for the input classes the record names; the note is that the store, rather than the caller's type, could enforce the record's "server assigned" clause by placing the spread first. `RoomStore.create` already ignores ids structurally because it takes `(name, capacity)`.
- not blocking: no test or record is unsatisfied now, and the hazard needs a future caller to pass a non-literal object carrying an id.

### RV-002 — advisory — implementer

- spec_ids: `room-booking-api:INV-006`
- evidence: `design/tech.md` M-03 `parseUtcMinute` — "returns epoch milliseconds only when the value is a string matching `YYYY-MM-DDTHH:mm:00Z` that denotes a real calendar instant, and `undefined` for any other input"; `src/time/index.ts:17` — `Date.UTC(year, month - 1, day, hour, minute)` maps a year of 0-99 onto 1900+year, so `0026-11-02T09:00:00Z` (format-valid, real instant) yields 1926 in the exactness check at `src/time/index.ts:19-25` and comes back `undefined`.
- effect: the function rejects one class of format-valid real instants; no record names a pre-1000 year and INV-006's boundary classes (minute precision, second precision, offset, missing Z) all behave as required, so nothing contractual is broken.
- not blocking: the record's obligations are met for every named input class; a guard such as requiring a four-digit year ≥ 1000, or building the epoch via `Date.UTC` with the year set explicitly, would close it.
