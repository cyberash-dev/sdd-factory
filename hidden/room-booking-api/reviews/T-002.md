## Findings

- **RV-001 — advisory, implementer.** `Date.UTC` treats years 0–99 as 1900–1999. For a booking from `0099-12-31T23:00Z` to `0100-01-01T01:00Z` and a query from `0100-01-01T00:00Z` to `0100-01-01T00:30Z`, INV-002 requires an overlap, but the booking start is interpreted as 1999 and `overlappingBookings` returns no booking. M-02 also requires `parseInstant` to return the actual epoch milliseconds for accepted spellings. This is newly noticed, and the missing earlier report prevents establishing that it was introduced by the rework; rule 16 therefore limits it to advisory.
- **RV-002 — advisory, test-writer.** The restart test uses `vi.resetModules()` within the same process, so it does not exercise stopping and restarting a process. For example, an implementation that persisted state only on process shutdown and restored it at startup could pass this test while violating INV-005. The assertion nevertheless flips for state persisting across this module reload, and the implementation itself uses module-local memory. This newly noticed test limitation is advisory under rule 16.

`choices:` The module-reload assertion counts as non-vacuous coverage, but is not equivalent to the specified process restart.
