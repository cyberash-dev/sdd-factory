## Findings

- **RV-001 — advisory, contract.** BEH-021 requires an empty POST body to yield 400 invalid_json, while BEH-025 and INV-006 say an absent body is accepted on every route. A zero-byte POST to `/rooms` has no distinguishable content in the M-08 interface: `src/index.ts:81` parses it and returns 400 invalid_json. The two expectations cannot both determine the body-syntax result for that input. This was first noticed on this review and is not shown to be a regression.
- **RV-002 — advisory, test-writer.** For a normal request sequence, an implementation that also opens an outbound connection could still satisfy all assertions at `tests/root/root.test.ts:201-216`; the flip test for CON-001 fails. No actual outbound connection was established by the evidence. This is not shown to be a regression.
- **RV-003 — advisory, test-writer.** An npm test run that skips another test or exits nonzero after this test has passed would not change the assertions at `tests/root/root.test.ts:293-305`. The verifier independently reports a nonempty, green, unskipped Vitest run, but this is not an assertion of the marked test or evidence of a separate `npm test` exit. This is not shown to be a regression.
