The record requires the suite to pass with outbound access blocked. The supplied Verifier evidence does not establish an offline run.

A product that persists state only across actual process restarts could pass both tests while violating the records. The SCN test does assert creation before the server restart, but does not stop or start a process.

- **RV-005 — advisory, implementer:** With `PORT=banana`, the approved assumption requires a nonzero exit; the entry selects port 3000 and starts serving instead. This is newly noticed and not established as a rework regression.
