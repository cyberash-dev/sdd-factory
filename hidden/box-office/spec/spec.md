# box-office product specification

> Generated by sdd-factory. Version 0.1.0; every record is `proposed` until the pre-authorised approval.

---

## 1. Context

An HTTP JSON API for selling tickets to events. Accounts register and log in; organizers create events with ticket tiers and discount codes; customers place orders that hold tickets for a while before they are paid; sold-out tiers carry a waitlist that is served when tickets come back; organizers read a per-event sales report. All state lives in the server process's memory. The product is a standalone TypeScript project started with `npm start`, listening on the port named by `PORT`.

---

## 2. Glossary

- **account** — the record `{ id, email, name, role }` created by `POST /users`; its `password` is stored and is never returned.
- **caller** — the account identified by the `Authorization: Bearer <token>` header of a request.
- **token** — the string returned by `POST /sessions` and presented in `Authorization: Bearer <token>`.
- **organizer** — the `role` value `"organizer"`.
- **customer** — the `role` value `"customer"`.
- **event** — the record `{ id, title, venue, startsAt, status, organizerId, tiers }`; its `status` is `"on_sale"` or `"cancelled"`.
- **tier** — a priced bucket of tickets inside an event, `{ id, name, priceCents, quantity, available }`.
- **available** — a tier's `quantity` minus its tickets in `held` and `paid` orders.
- **order** — the record `{ id, eventId, customerId, status, items, subtotalCents, discountCode, discountCents, totalCents, createdAt, expiresAt, paidAt }`.
- **status (of an order)** — one of `"held"`, `"paid"`, `"expired"`, `"cancelled"`, `"refunded"`.
- **hold** — an order in status `"held"`; it lasts until its `expiresAt`.
- **discount code** — the per-event record `{ code, percentOff, amountOffCents, maxUses, expiresAt, uses }`.
- **uses** — the number of the event's orders with a discount code that are `held` or `paid`.
- **waitlist entry** — the record `{ id, eventId, tierId, quantity, position }` for one customer and one tier.
- **position** — the 1-based rank of a waitlist entry among the entries of its tier, 1 being the first in line.
- **report** — the per-event sales summary `{ eventId, tiers, grossCents, discountCents, refundedCents, netCents }`.
- **money** — an integer number of cents (`priceCents`, `unitPriceCents`, `subtotalCents`, `discountCents`, `totalCents`).
- **time** — an ISO 8601 instant in UTC; requests accept anything `Date.parse` reads and responses always use `toISOString()` (`2026-11-02T18:00:00.000Z`).
- **id** — a string, unique across the whole API.
- **`PORT`** — the environment variable naming the port the server listens on.
- **`HOLD_SECONDS`** — the environment variable, default `600`, giving how long a held order lasts.

## 19. Out of scope

- Persistence: state does not survive a process restart, because the source keeps everything in memory.
- Payment capture and any external payment provider: paying an order changes only the order's status and `paidAt`.
- Email delivery, password reset, password change and password hashing rules: no endpoint of the source covers them.
- Token expiry, refresh and revocation: `POST /sessions` returns a token and no endpoint ends it.
- Currencies other than a single integer-cents amount, tax and fee computation.
- Analytics beyond `GET /events/:id/report`, and any export of the report.
- Transfers, exchanges or partial refunds of single tickets inside an order.
