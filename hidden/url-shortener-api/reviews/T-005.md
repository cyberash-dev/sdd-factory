## Spec conformance

Conforms.
- `url-shortener-api:CTR-006` — `resolvePort` returns 3000 for absent/empty, `invalid_port` for a non-integer or an out-of-range value (`src/index.ts:29-42`); `startServer` listens on the resolved port and rebuilds the handler with the *bound* port so `shortUrl` carries the configured port unchanged (`src/index.ts:87-97`, `src/routes/links/index.ts`); `main` writes `invalid_port` to stderr and sets exit status 1 before binding (`src/index.ts:99-107`). Conforms.

- `url-shortener-api:BEH-012` — `routeLinks` returns `undefined` for any method other than POST on `/links` and GET/DELETE on `/links/:code`, `routeRedirect` returns `undefined` for non-GET, so an unsupported method reaches the fallback with the store untouched. Conforms.
