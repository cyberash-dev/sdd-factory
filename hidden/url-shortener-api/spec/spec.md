# url-shortener-api product specification

> Generated by sdd-factory. Version 0.1.0; every record is `proposed` until the pre-authorised approval.

---

## 1. Context

A small HTTP service, "shortly", that shortens absolute http/https URLs into 6-character codes and redirects
requests for those codes to the original URL. Every request is served from a single process; all state lives in
memory and disappears when the process stops (source L3).

The boundary is the HTTP API plus the process configuration that starts it: the server listens on the port given by
the `PORT` environment variable, default `3000`, and is started with `npm start` after `npm run build` (source L7-L8).
The service performs no persistence, authentication, rate limiting or custom-code handling (source L45).

Acceptance is mechanical: the build compiles and the test suite passes; tests may start the server on an ephemeral
port (source L49).

---

## 2. Glossary

- **Link** — one stored association between an original URL and a code, holding the redirect hit counter and the
  creation timestamp (source L16-L17, L24, L29).
- **code** — the 6-character identifier from `[a-zA-Z0-9]` that addresses a Link, unique among existing Links
  (source L17).
- **original URL** — the absolute http or https URL a Link was created from; it is echoed back as `url` and used as
  the redirect target (source L14, L16, L24).
- **short URL** — the string returned as `shortUrl`, formed as `http://localhost:<port>/<code>` (source L16).
- **redirect** — the `GET /:code` request that answers `302` with the original URL in the `Location` header and
  counts as one hit (source L24).
- **hit counter** — the number of redirects performed for a Link, exposed as `hits` (source L24, L29).
- **createdAt** — the ISO-8601 timestamp at which a Link was created (source L29).
- **in-memory state** — the whole set of Links held inside the running process and lost when it stops (source L3).
- **error code** — the stable snake_case identifier carried in the single `error` field of every error response
  (source L39).
